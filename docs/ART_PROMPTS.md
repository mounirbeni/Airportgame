# Atlas Air 3D (airport & airline tycoon) — Art prompts

Generate each image with the exact **file name**, **size** and **format** below and send them back with the same names.
The game will use them as textures and UI art, keeping the current procedural look as a fallback.

## Shared style — paste at the end of every prompt

> Style: warm Moroccan golden-hour light, clean semi-realistic mobile game art, crisp shapes readable on small phone screens. Palette: ivory #F2ECDF, midnight teal #0F3F45, copper #B8743D, terracotta #B5583A, desert ochre #C79A66, sunset orange #F2A86B. Original design: no real airline names, logos or liveries, no watermark, no signature, no text unless requested.

Rules:
- **Textures** must be flat and top-down (or front-on), evenly lit, with no perspective, shadows or vignette.
- **"Seamless"** means the image must tile left-right and top-bottom with no visible seam.
- **Transparent PNG** means a real alpha background (no checkerboard drawn into the image).
