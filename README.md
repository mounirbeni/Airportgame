# Atlas Air 3D — أطلس للطيران

لعبة جوال أفقية ثلاثية الأبعاد (iOS / Android) بمحرك **Godot 4.4 (stable)** وGDScript مُنمَّط:
تقود طائرة ركاب وتبني شركة طيران مقرها الدار البيضاء. الواجهة عربية أولًا (RTL) مع خيار الإنجليزية، وتعمل كاملة دون اتصال.

## حالة التحقق (بصراحة)

| الفحص | النتيجة |
|---|---|
| تحليل نحوي لكل ملفات GDScript بأداة مستقلة (`gdtoolkit 4.3.3 / gdparse`) | ✅ نجح: لا أخطاء نحوية |
| محاكاة رقمية لنموذج الطيران (نسخة Python من نفس المعادلات) | ✅ إقلاع ≈ 23 ث / 770 م، اقتراب 3° ≈ ‎-520 قدم/د، تسوية ≈ ‎-410 قدم/د، توقف بالفرامل ≈ 600 م |
| تشغيل Godot (استيراد headless، اختبار الدخان، تشغيل المشهد) | ❌ **لم يُشغَّل**: مُنع تشغيل ملف Godot التنفيذي في بيئة البناء |
| تصدير Android / iOS، اختبار على جهاز، قياس FPS | ❌ لم يُنفَّذ؛ هدف 30 إطارًا/ث **غير مُتحقَّق منه** حتى يُقاس على جهاز فعلي |

لذلك أول خطوة عندك هي تشغيل الأمرين في «التحقق المحلي» أدناه.

## التشغيل على سطح المكتب

1. ثبّت Godot 4.4.1 stable (أو أي 4.4.x / 4.5.x).
2. افتح المشروع: `godot -e --path .` (أو Import ثم اختر `project.godot`). يُجري المحرر الاستيراد تلقائيًا أول مرة.
3. اضغط F5 أو: `godot --path .`

### التحقق المحلي

```bash
godot --headless --path . --import            # استيراد + فحص تحميل السكربتات
godot --headless --path . res://tests/smoke_test.tscn   # اختبار الدخان؛ رمز الخروج 0 = نجاح
```

يفحص اختبار الدخان: تحميل البيانات والترجمة، خصم تكلفة العقد مرة واحدة، دفع الأجر مرة واحدة ورفض التكرار،
فتح العقد الثاني، الحفظ والاستعادة، ترحيل حفظ قديم، شراء الترقية وأثرها على الدفع،
ثم إقلاعًا وهبوطًا وكبحًا حتى التوقف باستخدام نفس أوامر الإدخال. يستخدم ملف حفظ منفصلًا فلا يمس تقدّمك.

## التحكم

| الإجراء | لوحة المفاتيح | اللمس |
|---|---|---|
| رفع المقدمة / خفضها | S أو ↓ / W أو ↑ | عصا يمين الشاشة (اسحب للأسفل = رفع المقدمة) |
| الميل والتوجيه الأرضي | A/D أو ←/→ | العصا يمينًا/يسارًا |
| الدفع | Shift أو E لزيادته / Ctrl أو Q لخفضه | منزلق الدفع الدائم يسارًا |
| الفرامل (على الأرض) / مكابح هوائية (في الجو) | Space أو B (مع الاستمرار) | زر «فرامل» |
| تبديل الكاميرا | C | زر «كاميرا» |
| الإرشاد تشغيل/إيقاف | G | من الإيقاف المؤقت أو الشريط العلوي |
| إيقاف مؤقت | Esc أو P | زر II |
| إعادة الاقتراب بعد فشل | R | زر في لوحة الفشل |

اللمس متعدد الأصابع: لكل أداة رقم لمس خاص بها، فيمكن التوجيه مع تحريك الدفع أو ضغط الفرامل معًا.
تُحرَّر كل المدخلات المستمرة عند إلغاء اللمس، أو فقدان التركيز، أو الإيقاف المؤقت، أو إيقاف التطبيق.
على سطح المكتب، `emulate_touch_from_mouse` مفعّل لتجربة أدوات اللمس بالفأرة.

## رحلة تجريبية سريعة (CMN ← RAK)

1. عند البوابة: اختر «الدار البيضاء ← مراكش» واضغط «قبول».
2. زد الدفع قليلًا (≈ 15–20%) واتبع الخط الأصفر والحلقات الأرضية؛ انعطف يمينًا إلى الممر.
3. توقف عند خط الانتظار الأصفر (أضواء كهرمانية)، ثم ادخل المدرج وانعطف يمينًا واصطفّ.
4. دفع كامل؛ عند ≈ 115 عقدة اسحب للخلف برفق حتى ≈ 8°، ثم اصعد ومرّ عبر الحلقات النحاسية.
5. بعد علامة الاقتراب (حلقة فيروزية) خفّض الدفع إلى ≈ 25% وأبقِ المقدمة ≈ +1°…+2°.
   أضواء PAPI يسار المدرج: أبيضان وأحمران = على المسار.
6. قرب 40 قدمًا: الدفع صفر وارفع المقدمة قليلًا (تسوية)، المس الأرض، ثم الفرامل حتى التوقف.
7. تظهر النتيجة: تقييم الهبوط، العائد، التكلفة، الربح. «العودة إلى الدار البيضاء» يحفظ التقدّم.
8. يُفتح عقد «الدار البيضاء ← فاس»؛ ومن «الحظيرة» تشتري «حزمة الدفع النحاسية» (9000 درهم) فتظهر على الطائرة وتزيد الدفع 22%.

## البنية

```
project.godot            إعدادات (Mobile renderer، أفقي، autoloads)
scenes/main.tscn         المشهد الرئيسي (يبني العالم برمجيًا)
data/aircraft.json       أداء الطائرة والترقيات
data/world.json          المطارات والعقود والمسارات
localization/ar.json|en.json  كل النصوص ونصائح الطيران
scripts/core/            SaveSystem (حفظ مُرقَّم بالإصدار وذري)، GameState (الاقتصاد والتقدّم)، Loc، FlightInput
scripts/data/            تعريفات مُنمَّطة للطائرة/المطار/العقد + DataDB
scripts/aircraft/        aircraft_controller (نموذج الطيران)، aircraft_model (نموذج إجرائي)، engine_audio
scripts/camera/          كاميرا مطاردة بتنعيم (3 أوضاع)
scripts/world/           terrain، airport_builder (قابل لإعادة الاستخدام لكل مطار)، scenery، world_env
scripts/mission/         mission_controller (مراحل العقد والتقييم)، waypoint_marker
scripts/ui/              hud، touch_controls، panels
scripts/hangar/          الحظيرة ثلاثية الأبعاد
tests/                   اختبار الدخان headless
```

- **نموذج الطيران**: رفع = ضغط ديناميكي × معامل رفع حسب زاوية الهجوم، سحب طفيلي ومُستحث، انعطاف منسَّق مع مساعدة رفع خفيفة، تحذير وانهيار عند تجاوز زاوية الانهيار، توجيه بعجلة المقدمة وكبح على الأرض.
- **تقييم الهبوط**: معدل الهبوط، الانحراف عن خط المنتصف، خطأ الاتجاه، نقطة الملامسة بعد العتبة، السرعة. حدود متسامحة (انهيار عند > 1475 قدم/د، ميل > 20°).
- **الدفع الآمن**: كل عقد مقبول يأخذ `run_id`؛ `GameState.complete_run` يدفع مرة واحدة لكل `run_id` ويعيد النتيجة نفسها لأي تكرار. الحفظ: `user://atlas_air_save.json` (الإصدار 1) مع ‎.bak.
- **الفن**: كل النماذج والمواد والصوت إجرائية وأصلية؛ لا أصول خارجية ولا تراخيص مطلوبة.

## الجودة والأداء

- مُصيِّر Mobile، مواد بسيطة، MultiMesh للعلامات والأضواء والمباني.
- إعداد «عالية»: ظلال الشمس (≈ 260 م)، MSAA 2x، توهج. «منخفضة»: بلا ظلال/MSAA/توهج، دقة ثلاثية الأبعاد 75%، تضاريس أخف (كثافة التضاريس والمناظر تُطبَّق عند إعادة التشغيل).
- لم يُقَس الأداء على أي جهاز.

## التصدير إلى Android وiOS

`export_presets.cfg` يحوي إعدادَي Android (arm64‑v8a، APK) وiOS (arm64). البيانات (`data/*.json`, `localization/*.json`) مُضمَّنة عبر include_filter.

المتطلبات التي **لم تتوفر هنا** ويجب إعدادها:

**Android**
1. قوالب تصدير Godot 4.4.1 (Editor ← Manage Export Templates).
2. OpenJDK 17 وAndroid SDK (platform-tools، build-tools 34، platform 34)؛ اضبط مساراتهما في Editor Settings ← Export ← Android.
3. Keystore للتوقيع (debug يُولَّد تلقائيًا؛ release يحتاج keystore خاصًا بك).
4. `godot --headless --path . --export-release "Android" build/android/AtlasAir3D.apk`

**iOS**
1. جهاز macOS مع Xcode وقوالب تصدير Godot.
2. حساب Apple Developer: أدخل `application/app_store_team_id` وملفات التوقيع.
3. `godot --headless --path . --export-release "iOS" build/ios/AtlasAir3D.ipa` ثم افتح مشروع Xcode الناتج للتوقيع والتثبيت.
